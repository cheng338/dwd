Welcome to dwd's documentation!
===============================

This package provides linear and kernel distance-weighted discrimination
with scikit-learn-compatible estimators. The kernel estimator offers repaired
reference and optimized implementations with an unregularized intercept.

See the `kernel guide <https://github.com/cheng338/dwd/blob/master/docs/kernel_dwd.md>`_
for objectives, parameters, stopping rules, and numerical controls, and
`installation and examples <https://github.com/cheng338/dwd#readme>`_
for current usage.
